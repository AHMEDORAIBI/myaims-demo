# myAIMS Rehabilitation Center — GitHub Demo

Interactive front-end demo prepared from the myAIMS clinic-management concept.

## Included modules
- Dashboard
- Patients
- Appointments
- Billing / Invoices
- Receipts / Payments
- Expenses
- Reports
- Settings
- Arabic / English switch
- Browser-local demo data using `localStorage`

## Important
This is a **demo version** for presentation purposes. It contains no real patient information and has no production database or authentication backend.

## Publish with GitHub Pages
1. Create a new GitHub repository, e.g. `myaims-demo`.
2. Upload `index.html`, `styles.css`, and `app.js` to the repository root.
3. Commit the files.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main` and folder `/ (root)`, then Save.
7. GitHub will provide the public demo URL.
